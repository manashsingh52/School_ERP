# Sample sheets for Import from Excel

No data in a spreadsheet yet? Print `../forms/Student-Details-Form.pdf` (one A4 page) for each student:
parents fill sections A and B, the office fills C, and the fields follow the order of sheets 4, 5 and 6
below so each form types straight in.

Give these to a new school to fill in. Each file's first sheet is the data (row 1 is the column
names Bastaa recognises: keep them), and its second sheet, **How to fill**, explains every column.
Orange columns are needed; green ones are optional. The sample rows show the format and can be
overwritten.

| # | File | Upload in Bastaa | Before it |
|---|---|---|---|
| 0 | `0-School-details-to-collect.xlsx` | Not uploaded: typed into the setup wizard (school profile, academic year, fee heads, fee structures, installments, concessions, timetable periods, holidays) | — |
| 1 | `1-Classes.xlsx` | Import from Excel → Classes & sections | The academic year exists |
| 2 | `2-Subjects.xlsx` | Import from Excel → Subjects | Classes |
| 3 | `3-Teachers.xlsx` | Import from Excel → Teachers | — |
| 4 | `4-Students.xlsx` | Import from Excel → Students (parents come from the phone columns) | Classes |
| 5 | `5-Optional-fees.xlsx` | Import from Excel → Optional fees | Students, and published fee structures with those optional fees |
| 6 | `6-Fees-already-paid.xlsx` | Payments → Import earlier payments (needs permission to collect fees) | Optional fees, then the bills generated (Fees → Invoices) and finished |
| 7 | `7-Exam-marks.xlsx` | Examinations → an exam → Marks → upload | A sample only: download the real sheet for each class and subject from that screen |

Formats everywhere: dates day first (`14/03/2016`), mobile numbers 10 digits, Excel (.xlsx) or CSV,
up to 2,000 rows per file. Every row is checked before anything is saved, and rows with a problem
come back with the reason in an Excel file to fix and upload again.

The sheets are generated by `build.py` from the importer's own column names, and
`apps/api/test/import-samples.e2e.test.ts` uploads all of them through the real importer, in this
order, failing if a single row is rejected. After changing the importer, update `build.py`,
run `python3 docs/samples/imports/build.py` and run that test.
